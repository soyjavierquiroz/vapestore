# Vapestore

Lightweight custom WordPress + WooCommerce storefront code for `vape.kurukin.com`.

Live WordPress root:

```text
/home/vape.kurukin.com/public_html
```

Repository layout:

```text
theme/vapestore/          Custom storefront theme
plugins/vapestore-core/   Store-specific custom behavior, only when needed
```

This repository intentionally versions only project-owned code and notes. WordPress core, WooCommerce, third-party plugins, uploads, cache, backups, generated files, credentials, and `wp-config.php` are not versioned here.
